# Preparación de webcam — 2026-10-06

Cambio solicitado y realizado con asistencia de IA: formulario centrado de 896 px, tarjeta unificada, control segmentado de cruces, actualización de dispositivos con icono y footer integrado. Se reutiliza CameraPicker para seleccionar y crear ubicaciones sin cambiar sus contratos. Se conserva la paleta original de FlowSight en ambos temas, según la corrección posterior del usuario.

Validación: build de producción; 33 pruebas de componentes (preparación, selector y detalle); recorrido Playwright de preparación en escritorio y móvil, sin desbordamiento y con verificación de colores oscuros. El envío del modo access y del dispositivo seleccionado se verifica mediante API simulada. No se verificó captura con hardware real en este cambio.
