# UI: Comparaciones e insights

Pantalla o flujo **aparte** del resultado de una sola sesión (007). No redefine el tablero individual ni el chat mínimo (008).

## Entrada

- Desde el historial de sesiones procesadas: el analista elige **al menos dos** sesiones de archivo completadas.
- Indica el **nombre de zona** a alinear.
- Eje inicial: **sesión vs sesión** (P1). Controles de día / horario / zona solo si P2 está implementado; si el eje no aplica, se informa sin ranking inventado.

## Contenido

1. **Columnas**: nombre de sesión (o grupo), cámara o fecha visibles; sin UUIDs como único rótulo.
2. **Tabla o lista de cifras**: mismas familias en cada columna; no disponible con motivo; sin cero inventado; diferencia/relación solo con ambos lados disponibles.
3. **Filas opcionales** (funnel, patrones, posible compra): visibles si alguna columna las tiene; lado ausente = no disponible; rótulo de estimación cuando corresponda.
4. **Insights**: frases cortas verificables; o mensaje de sin diferencias / faltan datos. No causan, no ventas, no identidades.
5. Webcam / incompletas: no aparecen como columnas válidas (o el intento explica el rechazo).

## Fuera de esta pantalla

- Chat mínimo: no narra comparación ni insights.
- Cambiar tramo o local en el resultado individual: no altera ni dispara esta comparación.
- Vista en vivo (009): sin entrada a comparación completa.
