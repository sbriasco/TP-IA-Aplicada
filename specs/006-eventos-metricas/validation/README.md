# Contraste manual

Este directorio es para el contraste de un clip real. No forma parte de la suite y no promete que el conteo automático coincida con el conteo a mano.

## Qué contar

Sobre el mismo clip y la misma escena configurada, anotar a mano:

- entradas confirmadas del local
- salidas confirmadas del local
- pasos por la zona frontal que no entran

No hace falta anotar permanencia ni ocupación para cerrar esta historia.

## Cómo registrar la diferencia

Seguir el protocolo de diferencias del experimento 001: cada diferencia se clasifica (cruce de más, cruce de menos, paso de más, paso de menos) con el instante de video, sin rutas del equipo ni datos personales. El informe vive en este directorio cuando el equipo lo haga. No se inventa un `reference-run` ni se sube el clip al repositorio.

Hasta ese informe, las entradas, salidas y pasos del clip real quedan sin contrastar. El caso sintético de [quickstart.md](../quickstart.md) sigue siendo el recorrido que la suite ejecuta.
